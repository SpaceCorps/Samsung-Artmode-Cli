Contact & Support

We welcome bug reports, TV compatibility feedback, feature proposals, and community contributions for Samsung Art Mode CLI.

Primary Support Channels

  • GitHub Issues: For reporting TV pairing bugs, protocol edge cases, or feature requests, visit our issue tracker at github.com/SpaceCorps/Samsung-Artmode-Cli/issues.
  • GitHub Discussions: For automation ideas, Home Assistant integration patterns, and smart home discussions, join our GitHub Discussions at github.com/SpaceCorps/Samsung-Artmode-Cli/discussions.
  • SpaceCorps Organization: Discover more open-source developer and agent CLI tools at github.com/SpaceCorps.

Security Inquiries

If you discover a potential vulnerability within the local keystore logic or binary transport routines, please file a report via GitHub Private Vulnerability Reporting on the repository page.

Privacy Policy & Security Standards

Last updated: September 24, 2026. This Privacy Policy details the data handling, storage practices, and network communications of the Samsung Art Mode CLI binary and documentation website.

1. 100% Local Network Communication

Samsung Art Mode CLI operates strictly across your local home network (LAN). All WebSocket commands and TCP image transfers connect directly from your machine to your Samsung TV's local IP address (ports 8001 and 8002). No artwork, images, device identifiers, or commands are ever transmitted to any cloud servers or third-party relay services.

2. Zero Telemetry & No Analytics

The CLI binary contains zero tracking code, zero analytics SDKs, and zero telemetry beacons. We do not collect error logs, IP addresses, feature usage statistics, or session counts. What you display on your TV remains entirely private to your household.

3. Native Operating System Keystore Protection

Authentication tokens generated when pairing with your TV are treated as sensitive credentials. By default, tokens are never written in plain text to configuration files. Instead, they are delegated to your operating system's native secure credential vault (macOS Keychain, Windows DPAPI, or Linux Secret Service via libsecret). Non-secret metadata (host IP and model name) is stored in a user-restricted local configuration file (chmod 0600 on POSIX systems).

4. Documentation Website Privacy

This static documentation site is hosted on GitHub Pages. It contains no tracking scripts, cookies, or marketing pixels. Access logs are processed strictly by GitHub in accordance with GitHub's standard Privacy Policy.
